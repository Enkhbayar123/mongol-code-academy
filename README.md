# Mongol Code Academy: AI-Transformed IT Education (AX)

## 1. Main Theme: Solving Practical Industrial Problems with AX
**The Industrial Problem:** The Mongolian IT sector faces a critical shortage of skilled software engineers. Traditional education systems struggle to provide personalized mentorship, up-to-date curriculum, and psychological support for students facing the steep learning curve of programming.
**The AX (AI Transformation) Solution:** Mongol Code Academy transforms the traditional educational model into an AI-driven learning ecosystem. By integrating AI at the core of the student experience (via **MongolGPT**), we provide 24/7 personalized academic tutoring, career roadmapping, and crucial psychological support, effectively scaling high-quality mentorship to every student.

## 2. Project Overview
Mongol Code Academy is a modern, interactive coding platform designed to train the next generation of developers. 
Key features include:
- **Interactive Curriculum:** Step-by-step learning paths for modern web development.
- **Practice Hub:** A LeetCode-style environment for practicing algorithms (e.g., Two Sum).
- **MongolGPT (AI Counselor):** A Gemini-powered AI assistant that acts as a personalized mentor, providing coding help, career advice, and stress management.
- **Community & Video Learning:** Engaging, rich visual UI designed to keep students motivated.

## 3. Technical Architecture and Plan
### Architecture
- **Frontend:** React.js, Vite, React Router for dynamic Single Page Application (SPA) routing.
- **Styling:** Tailwind CSS with custom glassmorphism and animated canvas elements for a premium, engaging user experience.
- **Backend & Authentication:** Firebase (Authentication and Hosting).
- **AI Integration (AX Engine):** Google Gemini API integrated seamlessly into the platform to power the `MongolGPT` counselor.

### Future Plan
1. **Phase 1 (Current):** Prototype UI, Firebase Auth, Basic Curriculum, and Gemini AI integration.
2. **Phase 2:** Implement interactive code execution environments (sandboxed IDE) inside the browser.
3. **Phase 3:** AI-driven personalized learning paths based on student performance metrics.

## 4. Prototype Implementation
The prototype is fully functional and implemented in the `src/` directory. 
- Run `npm run dev` to launch the application.
- Explore the **Home**, **Courses**, **Practice Hub**, and **MongolGPT** modules.
- The UI features a dark-mode aesthetic with vibrant micro-animations to maximize user engagement.

This document, combined with the working prototype, clearly demonstrates how we are leveraging AI to solve the practical industrial challenge of scalable, high-quality technical education. The platform is not just a course list; it is an AI-augmented educational environment.
